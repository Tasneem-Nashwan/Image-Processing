# Image-Processing
A simple image processing project using Python

Project Description

This project demonstrates basic image processing techniques using Python and OpenCV in a Jupyter Notebook.

The project includes several image processing operations, such as:

- Adjusting image color saturation.
- Resizing images.
- Converting images to grayscale.
- Displaying and processing images.

Libraries Used

Python: 3.10.20 
OpenCV: 5.0.0
Numpy: 2.2.6
Matplotlib: 3.10.9

Technologies

- Python
- Jupyter Notebook
- OpenCV
- NumPy
- Matplotlib

Project Type

A simple educational project for practicing fundamental image processing techniques.
